# ADR 0002：组合区同时提供结构视图与包视图，多行包自动建包组

- 状态：已接受
- 日期：2026-11-10

## 背景

用户对预设的心智模型是「包 → 行」，但 Cordis 的预设组合里只有两种节点：行与结构组（`cordis:group`）。包只是行的 `name` 来源，不是节点，也没有显示名。若只按结构画，用户看不到「我收了哪些包」；若只按包画，结构组与 `isolate` 无处安放。

## 决策

- 组合区提供两种视图，读同一份数据：「结构视图」按 YAML 层级展示根、组、行，组可折叠；「包视图」按行的包名归并成卡片，包可折叠。
- 收录一个贡献多行的包时，自动在预设里创建一个以包名派生的结构组（`cordis:group`）把行包住；单行包不建组，直接呈现为一行。

## 理由

- 包视图直接对应用户的收录心智；结构视图是唯一能编辑 `isolate` 的地方。
- 自动包组让两种视图在大多数情况下重合，切换时不会「迷路」；结构组在被设置 `isolate` 前没有运行时副作用。
- 单行包不建组，避免为每个包都加一层无意义嵌套。

## 代价

- 自动包组会在用户没有要求的时候改变 YAML 结构；组没有显示名，只能靠 id 与子行的包名辨认。
- 两种视图的增删改都要维护同一份模型，客户端实现复杂度上升。

## 备选

- 只做结构视图：`isolate` 好编辑，但用户看不到包归属。
- 只做包视图：直观，但结构组与 `isolate` 只能降级到手写 YAML。
